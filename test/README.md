# Меню на экраны кофейни

Две страницы для телевизоров: `1.html` — горячее меню, `2.html` — холодное.
Меню свёрстано текстом, а не картинкой: весит ~20 КБ вместо мегабайтов,
рисуется в родном разрешении экрана и правится прямо в HTML.

## Как поменять цену или позицию

Откройте нужный файл, найдите строку и поменяйте число:

```html
<div class="row"><span class="row__name">Латте халва</span><span class="row__price">300</span></div>
```

Новая позиция — скопируйте такую же строку и впишите своё.
Разделы устроены так же, по образцу соседних.

Телевизор проверяет обновления раз в 30 минут и перезагружается сам,
когда файл на GitHub изменился. Если интернета нет — продолжает
показывать то, что уже загружено, экран не гаснет.

## Название кофейни

В обоих файлах стоит заглушка `[Название кофейни]` — замените на своё
(или удалите строку `<span class="head__shop">`, если не нужно).

## Видео

В шапке каждой страницы есть блок под ролик:

```html
<video autoplay muted loop playsinline preload="metadata" poster="media/hot-poster.jpg">
  <source src="media/hot.mp4" type="video/mp4">
</video>
```

Пока роликов нет — показывается постер из `media/`. Положите
`media/hot.mp4` и `media/cold.mp4`, и они подхватятся сами, вёрстку
менять не нужно. Если файла нет или кодек не поддерживается, страница
молча остаётся на постере.

Размер блока на экране — 584×256 точки. Кодировать имеет смысл в
1168×512, дальше уже не видно разницы, а вес растёт.

## Что где лежит

| Файл | Зачем |
|---|---|
| `1.html`, `2.html` | сами меню |
| `style.css` | оформление, палитра и кегли в самом верху |
| `app.js` | масштаб под экран, полный экран, проверка обновлений |
| `sw.js` | офлайн-кэш |
| `fonts/` | шрифты, кириллический сабсет, 83 КБ |
| `media/` | постеры и, когда появятся, ролики |

Шрифты лежат в репозитории специально: внешний CDN при плохой связи —
лишняя точка отказа, а если шрифт не загрузится, меню поедет.

## Важно: нужен GitHub Pages

Офлайн-кэш (`sw.js`) работает только по HTTPS с правильными
content-type. По ссылке на `raw.githubusercontent.com` страница не
откроется как страница. Включите Pages: Settings → Pages → Deploy from
a branch → main.

## Если поменяли меню, а экран показывает старое

Он обновится сам в течение 30 минут. Быстрее — перезагрузить страницу
на телевизоре дважды: первый раз подтянется новая версия в кэш, второй
раз она покажется.
